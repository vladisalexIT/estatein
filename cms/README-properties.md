# Инфоблок недвижимости Estatein

## Назначение

Единый источник данных для карточек недвижимости на Home и Properties.

На текущем этапе все ссылки карточек должны вести на /property-details/.
Отдельные детальные страницы для каждого элемента не создаются.

## Инфоблок

- Тип: estatein_content
- Символьный код: properties
- Название: Недвижимость
- Разделы не используются.
- Числовой ID указан в local/config/estatein.php.

## Стандартные поля элемента

- NAME — название объекта.
- CODE — уникальный символьный код.
- ACTIVE — активность.
- SORT — порядок на странице Properties.
- PREVIEW_PICTURE — изображение карточки.
- PREVIEW_TEXT — описание карточки, обычный текст.

## Свойства

- PRICE — число, обязательное; цена в USD без форматирования.
- BEDROOMS — число, необязательное.
- BATHROOMS — число, необязательное.
- PROPERTY_TYPE — строка, необязательная.
- CARD_TAG — строка, необязательная.
- IMAGE_ALT — строка, обязательная.
- SHOW_ON_HOME — одиночный список, обязательный.
- HOME_SORT — число, необязательное.
- HOME_DESCRIPTION — строка, необязательная; описание для главной.

SHOW_ON_HOME:
- Нет: XML_ID = N, значение по умолчанию.
- Да: XML_ID = Y.

Если HOME_DESCRIPTION пустое, на главной используется PREVIEW_TEXT.

## Начальные элементы

1. seaside-serenity-villa — сортировка 10, показывать на главной.
2. metropolitan-haven — сортировка 20, показывать на главной.
3. rustic-retreat-cottage — сортировка 30, показывать на главной.
4. coastal-elegance — сортировка 40.
5. urban-vista-apartment — сортировка 50.
6. countryside-haven — сортировка 60.

Повторяющиеся демонстрационные слайды не создаются как отдельные элементы.

## Хранение данных

Структура инфоблока и элементы находятся в базе данных Битрикс.
Загруженные картинки находятся в файловом хранилище Битрикс.
Git не содержит резервную копию базы данных или загруженных картинок.

При переносе на другую установку числовой ID инфоблока может отличаться.
